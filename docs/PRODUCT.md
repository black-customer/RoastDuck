# 产品契约：把自己的意思一句句表达出来
状态：2026-09-10当前，句子主线见SENTENCE_STUDY，本轮增量见PERSONAL_FOCUS；实际完成与验证见PROJECT_STATUS。
## Platform
web
## 目标
帮助雅思备考者把自己的意思转为自然英文，通过回想、自评和间隔复习减少表达卡壳。句子学过、自评和真实独立输出分别记录。
## 默认路线
首页是十二周活动记录与学习/复习两个入口。按题选择或帮我选一道有材料的题；同模式有未完成句子会话时直接续接。
自由输入中文、英文或混合想法，先保存，再独立审核形成自然回答。整题按句序：完整中文→看自然表达/句内用法和注意点→脱口而出/想了一会儿/没想出来→下一句。无倒计时、无五项分组、无自动回插，无强制输出。
默认复习只调度到期句子。可选再表达一次、整题中文辅助、无提示独立回答共用Chloe老师与记忆；反馈不自动制卡，确认问题独立审核后记忆，可撤销。
## 材料
sentence-material-v1覆盖清楚原意，包括自然正确的句子；用法针对实际错误或未展示的准备意思。整句自然准确，保留个人事实、立场和话语功能。用户中文与根据英文整理分开标记，模糊/转写问题待确认。无音频不评价发音、流利度或完整口语分数。
自然全文与句子页面使用同一已审核版本。补充中文创建追加版本；原文、旧材料和进度保留。
强烈推荐中文原意但允许跳过；中文界定想表达的内容，英文提供能力与错误证据。新材料使用当代年轻美式风格，英式自然表达属于地域差异，不自动判错。纯中文只生成准备项，不虚构曾犯错误。
中文提示与英文示范支持持久黄色手动高亮；关注不等于不会，不修改FSRS。确认的旧错误供老师按证据检索，原错误默认折叠且不朗读；记忆可撤销、删除，不要求背错句。
## 拓展与兼容
WEB_SIMPLICITY及light_study_v1/v2、四步强化、表格/快速回顾只在/extensions主动进入，不影响默认推荐和句子FSRS。历史合同见archive/pre-sentence-study-2026-09-10。
## 声音与界面
文本DeepSeek V4.1 Flash（API名deepseek-flash）；默认mimo-v2.5-tts、Milo/en-US。自然跟练等待高质量声音，可显式快捷试听；快捷试听缓存优先，否则立即本机发声。声线、口音与播放倍速分别设置，音源真实标记。
蓝色品牌、鱼形标识，灰蓝全屏与清楚阅读层级。代码驱动可操作路线，用户体验高于旧截图通过结论。
## 边界
只做Web，安卓/同步冻结，不查Windows偶发原生退出。开发Mock隔离库，历史材料离线零Runtime。按已授权的版本发布规则更新GitHub；公开仅使用无私人材料/Key/敏感Git历史的独立快照。
雅思口语体验验证后，再考虑安卓、通用口语、写作、阅读和听力。
