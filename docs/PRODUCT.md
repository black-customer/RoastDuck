# 产品契约：网页版雅思表达学习
状态：2026-09-08 已批准；实现与验收只看 PROJECT_STATUS。执行范围见 WEB_USABILITY。
## Platform
web
## 目标
帮助用户把真实想说却不会说的意思，低摩擦地转为可提取的自然英文；优先雅思口语表达，不承诺点击等于掌握或完整口语分数提升。
## 用户路线
选题 → 英文尝试（或明确不会）＋中文原意 → 原文保存和独立诊断审核 → 简短反馈和可学材料 → 轻松学 → 到期复习 → 可选无提示重答与前后证据。
轻学习全部入口使用 V2。五个表达一组，中文先行、揭晓、三档自评；旧 V1 未学位置接入新版，旧记录不删除。四步不是前置条件。
## 体验边界
保留蓝白视觉；页面突出一个主要动作，资料按需展开。声音默认 MiMo/en-US/Chloe，失败自动使用明确标识的备用声音；等待、失败不阻止文字学习。
查询默认不收藏。自然表达不因升级措辞制卡；无音频不评价发音和流利度。没有再次提及旧错误不等于修复。
不重新生成104份历史材料。Runtime文本仅deepseek-v4-flash，Key只存服务端，真实服务小样另获范围确认。
## 当前非目标
安卓、双端同步、签名、公开GitHub发布全部冻结。保留代码/数据，不作破坏性回退。
不增加选择题、拍照收集、新录音识别、发音评分、成长仪表盘、账号、云端或其他考试模块。
## 后续方向
雅思口语验证 → 通用英语口语 → 雅思写作 → 阅读/听力。网页得到PO认可后再安排安卓。
开源是后续独立交付：自带Key、公开样例、安装指引与许可/隐私审计；私人回答和未确认可再分发的教材不直接公开。
