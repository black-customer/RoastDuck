# 产品契约：网页版雅思表达学习
状态：2026-09-08 已批准；实现与验收只看 PROJECT_STATUS。最新范围见 WEB_SIMPLICITY；此前合同中未冲突的可靠性要求继续有效。
## Platform
web
## 目标
帮助用户把真实想说却不会说的意思，低摩擦地转为可提取的自然英文；优先雅思口语表达，不承诺点击等于掌握或完整口语分数提升。
## 用户路线
首页只突出十二周真实学习记录与“学习／复习”。没有未完成会话时再选按题或自动一组；有同模式未完会话时直接续接具体ID。收藏、题库、对话和设置从收起菜单进入，学习页无强制额外步骤。
选题 → 单框中文/英文/混合想法 → 原文保存和独立覆盖诊断审核 → 简短反馈、个人自然回答与材料 → 轻松学/快速回顾 → 到期复习 → 可选无提示重答。
轻学习全部入口使用 V2。五个表达一组，中文先行、揭晓、三档自评；旧 V1 未学位置接入新版，旧记录不删除。四步不是前置条件。
## 体验边界
保留蓝白视觉；页面突出一个主要动作，资料按需展开。声音默认 MiMo/en-US/Dean男声，失败自动使用明确标识的备用声音；等待、失败不阻止文字学习。
查询默认不收藏。自然表达不因升级措辞制卡；无音频不评价发音和流利度。没有再次提及旧错误不等于修复。
明确但没有英文成功证据的意思默认生成准备项，不冒充已犯错。我的雅思表达/我的对话表达为来源投影；快速回顾只读，累计学过与自评已会分开。首见评分就进入日级FSRS，三档为脱口而出/想了一会儿/没想出来。
本轮全量复核当前有效材料，只离线修订有问题内容；完整教学句同样需要独立审核。新增personal-spoken-v2具体回想实例，旧合同/源文/进度保留。Runtime文本仅deepseek-v4-flash，Key只存服务端，真实服务小样另获范围确认。
## 当前非目标
安卓、双端同步、签名冻结。GitHub黑客式全历史推送禁止；仅发布经筛选的独立快照。保留代码/数据，不作破坏性回退。
不增加选择题、拍照收集、新录音识别、发音评分、复杂仪表盘、账号、云端或其他考试模块。
## 后续方向
雅思口语验证 → 通用英语口语 → 雅思写作 → 阅读/听力。网页得到PO认可后再安排安卓。
