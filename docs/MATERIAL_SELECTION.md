# 四步选材契约：先确认表达缺口，再生成教材

> 状态：现行材料契约。轻学习只消费本契约已审核材料；本文件的编译阶段不是用户必须完成的学习步骤。

2026-09-06 PO 确认。版本 evidence_v2，四步顺序不变。

## 诊断依据

输入是英文原答与中文原意，不是题目译文与一篇范文。先按意思单元对齐；每个单元保存中英文原文引用及重复引用位置，全部非空白源字符有归属。自然表达、需要修复、未表达、不确定、非答案分别记录。

表达已经自然准确时，不因 AI 偏好更高级、更简短的同义表达而制造必练项。明确的错误、搭配不当、构式问题和确认的未表达意图可以训练；不确定 ASR、纯标点、非答案和无法证明的知识缺陷不训练。一次失败只证明本次薄弱，不宣称永久不会。

## 四个独立阶段

1. 意图对齐与 Gap 诊断：逐项原文证据、中文意思、问题、建议修复目标；不先生成整篇升级范文。
2. 独立诊断 Reviewer：逐个意思单元与候选 Gap 作 train / exclude / uncertain 裁决，必须引用本次原文；自然表达优先保护。不够证据不批准。
3. 教材编译：只接收已确认目标。自然正确部分尽量原样保留，仅修复必要内容；输出完整句子、意思单元 ID、Gap ID 与真实挖空表面形。
4. 独立材料 Reviewer＋确定性 Coverage：核对原意、必要修复、四列对应、中文提示清楚、句子／全文和空位。审核生成必要性，不只审文字好看。

各阶段不同 Prompt／请求／runId，持久检查点；网络失败只重试未完成阶段，内容拒绝保留原版本并显式重新生成。不消费开发期 Runtime 余额。

## 四列由证据编译

- 第一列：已审核 Gap 的明确中文功能提示，不把模糊中文当难题。
- 第二列：需要补足的表达／构式，而不是一句中所有好词；实例表面形和可接受同义变体分开。
- 第三列：所关联意思单元的已审核中文原意，不接受把 AI 改写逆向中译来替换。
- 第四列：最小必要修复后的自然句子；一条句子多个 Gap 不重复生成整句练习。
- 每行可展开原英文、中文证据和入选理由。完整自然全文可保留原本正确句子，但这些句子不自动入选第一、二步。
- 不确定和非答案保留账本，不进入正确输入材料；界面明确未纳入部分。无确认 Gap 为零行，不表扬成“全文完美”。

## 数据与兼容

v20 按材料保存阶段输入哈希、输入／输出快照、版本和运行证据，旧分析归档；新建采用 evidence_v2，旧会话保留原版本。历史回答不自动重跑；用户显式重新分析才建立新契约材料。开发期历史编译仍须离线独立证据，不伪造 ai_runs。

## 验证

固定校准样例必须覆盖：自然替代表达、已会表达被换高级说法、真实搭配错误、构式错误、只补局部而保留已会部分、遗漏意图、ASR 不确定、多 Gap 同句、无 Gap、引用漂移、第三列篡改、证据不足、Reviewer 排除、失败续跑与版本保留。Mock 只能验证契约，不代替真实语义验收。
