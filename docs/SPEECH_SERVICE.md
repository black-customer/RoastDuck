# 网页语音服务
状态：现行，2026-09-10；句子学习按SENTENCE_STUDY，实际服务验收见PROJECT_STATUS。
## 路径
mimo-v2.5-tts，默认en-US / Milo年轻男声；Dean仍可选，尊重用户主动选择的其他声线和来源口音。声线与口音解耦，不再将Milo固定成英音。
合成使用自然年轻成人交流风格，避免教学慢读和刻意低沉；不复制播客主持人声纹。播放倍速0.85/1/1.1/1.2独立保存，默认1，HTML音频保留音高；改变倍速不重新合成、不改变缓存身份。旧自动男声默认迁至Milo，明确女声及口音保留。
GET /api/speech/health只返回配置存在性、最近一次请求状态及安全错误码，既不合成也不检查余额。已配置不等于可用。
页面播放使用LightAudioPlayer协议；材料SpeakButton、FreeTalk与设置试听显示真实来源。句子学习揭晓前没有声音，短表达和例句分开播放。

## 两种播放行为
- `LightAudioInput.playbackMode`、`SpeakOptions.playbackMode` 和 `SpeakButton.playbackMode` 支持 `natural` / `quick`。
- `natural`：句子/例句/自然全文跟练，等待MiMo真实音频；慢请求与合成失败不自动换声。界面提供“先听快捷声音”，用户明确点击后改用quick。准备不阻塞文字学习。未知结果仍需显式确认才能重新付费合成。
- `quick`：优先播放器已准备的高质量字节，否则在同次点击立即调用本机英语声音，不发起MiMo合成。WebSpeech仅选择`localService===true`的英语声线；没有可用声线时明确说明，并提供准备自然声音。实际播放名称来自设备，不把系统声线标成MiMo。
- 未传模式保留拓展功能的旧3.5秒等待与自动备用兼容行为；新默认路线必须显式传模式。
- 自然等待期间改听quick会使旧播放失效，但允许已经提交的请求完成缓存，不会突然插播。再次点击自然/快捷时可复用已下载字节。
## 等待、排队与缓存
- 浏览器默认fetch必须通过globalThis调用，不能作为播放器实例的原生方法调用（会在请求发出前Illegal invocation并误降级）。现已覆盖真实浏览器Mock请求/音频下载/播放路径，不只是注入函数的单测。
- 当前与下一项按需准备并下载实际WAV/Blob；最多保留当前/下一/播放中项，换项释放对象URL；当前优先，取消过时预取；数据库speech_lane约束同库多Web进程单合成。
- 新自然播放没有3.5秒自动降级；quick冷播放没有网络等待。只对未传模式的旧拓展调用保留3.5秒兼容行为。
- 缓存按实际模型/风格请求/声音/口音/速度指令去重，purpose不制造重复；原子写WAV及SHA-256侧车校验。short-expression/daily-conversation/ielts-answer风格忠实读原文；旧指令缓存不冒充新版，旧文件仅按原ID兼容读取。
- 已发出请求的结果未知或坏缓存不静默反复付费。当前声音提供明确确认的重新合成；请求失败不伪报优质音源。
- 停止/换卡/离页通过播放所有权及代次失效；旧按钮卸载不能取消另一按钮的新播放。
- 逐句暂停可保留当前音频，折叠播放器则卸载并释放；无文本的播放按钮禁用。
## 隐私与验收
Key仅服务端配置；合成与凭据POST拒绝跨站简单请求。自动化在测试入口拦截Runtime，始终Mock。
开发没有小样真实试听授权时不调用。缺Key时明确说明；真实自然度由用户试听短表达、完整句和简短回复决定，不用Mock替代。
本轮不引入Qwen/Kokoro/ASR或安卓音频链，也不全书合成。
