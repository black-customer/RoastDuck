# Vibe Coding工程工作流
状态：现行；2026-09-07。约束风险与成果，不假设某代模型能力。
## 权威
README是文档索引，PRODUCT管范围，LEARNING_EXPERIENCE管行为，PROJECT_STATUS管真实结果，ROADMAP管后续。历史无现行约束力。
读AGENTS、当前状态、相关领域契约并检查git；无需每次读全部旧文档。架构/数据/证据语义变更先写契约和DECISIONS。
## 自主执行
主执行者负责实现、集成、必要重构与测试，可委派只读审查，交付后独立Review；PO不管理A/B。普通技术决定由开发者作出。
按逻辑阶段Commit并跑定向测试，最终完整npm run check。不每改一行跑全量，也不拿专项通过代替全量。
中断写当前commit、dirty范围、真实退出码、下一条命令；接手从检查点继续。
## 不变保护
迁移先备份；自动化Mock＋临时库/构建隔离；私人原文/Key隔离；独立内容Reviewer/覆盖；长任务版本/幂等/恢复。开发模型更强不减免。
自评只供轻学习调度，不冒充客观正确/旧四步完成；GET不创建业务记录。
产品目标、费用、隐私用途、外部发布与破坏性动作另获授权。
## 验收
治理检查静态索引/链接/活跃Prompt/迁移/隐私，不拿关键词当行为证明。npm run check唯一完整门；审查runner复用，不另造缩水版。
真实材料audit:readiness、真实语音、截图和学习效果分别留证。视觉沿用既有世界，集中检查/修正/确认，独立Review。
收工更新PROJECT_STATUS与实际DESIGN并Commit；工程通过不是学习提效或整版验收。
