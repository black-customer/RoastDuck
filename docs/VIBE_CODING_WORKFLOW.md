# Vibe Coding 工程工作流
状态：2026-09-10现行。不按模型型号设能力豁免。
## 三层要求
共同边界：隐私、费用、原文保留、编号迁移、独立内容审核、可恢复任务与真实证据。
项目事实：当前PRODUCT/LEARNING_EXPERIENCE/SENTENCE_STUDY、架构/接口、PROJECT_STATUS和已知问题。
按需手册：不熟悉模块时再读对应Skill、测试示例和局部契约，不每次阅读全部历史。
## 自主实施
开发者决定局部结构和定向验证，可委派清楚边界的实现与独立审核，不让PO管理多窗口。本轮界面代码驱动；不强制图片三方案、固定全面Review或多次全库测试。不修改全局Skill。
旧学习规则不得因历史文档重返默认产品。改变数据/证据语义先更新相关契约；普通样式/文案修改无需形式化加测试。
## 交接
按逻辑阶段验证与提交，记录实际commit、未提交范围、失败点、下一条命令。CI完整门保持，本地未运行不宣称通过。
内容Generator和Reviewer独立，结构检查不能批准；已发布句子与音频必须保留来源/版本。用户新反馈优先于旧截图认可。
真实服务与学习效果单独报告。安卓/同步冻结，Windows偶发退出不在本轮调查；公开操作按明确授权执行。
