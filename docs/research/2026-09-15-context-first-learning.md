# 语境优先的口语学习：证据与候选开发范围

日期：2026-09-15。状态：研究备忘与待确认提案，不是已批准执行契约，不替代 GUIDED_REVEAL、SENTENCE_STUDY 或既有费用授权。

本次只读核对代码与研究，未改变学习模式、用户资料或 Runtime。文献选择围绕当前产品问题，不是穷尽性系统综述；研究效应不能直接换算为本产品的雅思提分。

## 一、建议与不建议

建议把已有能力连接成：真实想表达的意思 → 自己尝试 → 按需获得针对性帮助 → 再次表达 → 之后在相关问题中重新使用。

整题提供上下文，句子和表达提供局部帮助，既有句子身份继续承担可追溯的复习记录。三个单位不必相同。整题同页是待验证的界面假设，不是已经证实优于所有逐句学习的方法。

不建议为了消耗开发额度扩展功能数量；不把图片、情感、联想数量等同于学习效果；不以“建立神经连接”作为一次交互有效的证据；不把看懂、跟读、当场修正和延迟独立表达混为一谈。

中文可以帮助澄清原意，不需要被禁止，也不应成为每次练习都必须逐字翻译的脚本。不会时可以直接求助或先看示范，不要求先痛苦地失败一次。

## 二、研究证据与边界

| 研究 | 可支持的结论 | 不能据此推导 |
| --- | --- | --- |
| [Webb、Yanagisawa、Uchihara，2020](https://onlinelibrary.wiley.com/doi/10.1111/modl.12671)：22 项研究的词汇活动元分析 | 闪卡、词表等显性活动可以建立词义/形式知识；延迟后表现下降，活动效果有差异 | 单词学习无用；背过即可在对话中灵活使用 |
| [Symons 与 Johnson，1997](https://digitalcommons.lib.uconn.edu/chip_docs/9/)：自我参照记忆元分析 | 联系自己通常有记忆优势；比较任务本身的组织和联想程度影响优势 | 所有内容都要编个人故事；直接证明第二语言口语自动化 |
| [Barcroft，2002](https://onlinelibrary.wiley.com/doi/10.1111/0023-8333.00186)：低中级学习者学习 24 个西语词 | 强加愉悦度联想或字母统计任务，可能妨碍记住新词形式；记住意义不等于记住外语怎么说 | 语境或理解有害；所有讲解都应取消 |
| [Kang、Gollan、Pashler，2013](https://laplab.ucsd.edu/articles/KangGollanPashlerPBR2013.pdf)：图片命名与口头检索实验 | 先尝试说词、再听反馈，优于只听后模仿的即时/两天后词汇表现，发音质量未下降 | 单词实验已经证明整题 App 提分，或每次必须先无助地卡住 |
| [Lyster 与 Saito，2010](https://kazuyasaito.net/SSLA2010.pdf)：15 项课堂口头反馈研究，827 人 | 对目标语言项目，纠正反馈有持续收益；促进自我修正的提示值得保留 | 逐句打断、全部纠错或特定 AI 反馈一定最好 |
| [Xu 与 Zeng，2023](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2023.1026174/full)：20 项反馈时机研究 | 立即与延迟反馈的优势受任务、定义和测量影响，没有统一最佳时刻 | “及时帮助”必须是持续监听、在每个错误发生时打断 |
| [de Jong 与 Perfetti，2011](https://sites.pitt.edu/~perfetti/PDF/de%20Jong%20Language%20Learning.pdf)：24 名 ESL 学生，重复完整讲话 | 同题重复组的部分流利度收益可延续到随后新话题独白 | 小样本独白等于真实对话或 IELTS 总分；产品必须强制 4/3/2 倒计时 |
| [Fang、Elgort、Chen，2024](https://doi.org/10.1017/S0272263124000184)：英语动词名词搭配检索 | 分散与集中练习的区别依测量而异；分散练习对部分自动化/隐性指标有利 | 所有任务都服从一条最优时间表；FSRS 的目标保持率就是口语掌握率 |
| [Kakitani 与 Kormos，2024](https://doi.org/10.1017/S0272263124000251)：116 名日本学习者，叙述练习 | 一天与七天间隔组在延迟新图片任务中总体相近，不能机械套用词汇间隔结论 | 需要把现有 FSRS 改成固定一天或七天；不再需要间隔 |
| [语境多样性研究，2026](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/effects-of-contextual-diversity-on-incidental-vocabulary-learning/F83A1EB55404E2E07FDC1695B0BC2BAE)：124 名学习者纳入分析 | 多样语境收益受到既有词汇量影响；先在熟悉情境建立基础，再变化情境值得试验 | 背景越多越好；该实验直接验证左右双栏界面 |

总体判断：保留有意义的输入、尝试提取、具体反馈、重复表达和间隔使用；不要把其中任何一个机制扩张成唯一方法。直接让用户想象情绪、增加装饰图片或强制填长表，并没有因此获得科学合理性。

IELTS 还分别评价流利连贯、词汇、语法与发音，权重相等。本产品的文字、示范音频与自评不能替代完整口语评价。[官方说明](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)

## 三、工程事实：哪些已经有，哪些真的缺

以下为当前源码核对，不等于本轮真实服务验收。

| 已有能力 | 当前实现 | 候选改进 |
| --- | --- | --- |
| 原文、草稿、追加回答版本 | `src/lib/app-services/answers.ts` | 将已有整题草稿与局部求助、后续修正关联，不再创建平行回答库 |
| 完整同版自然句和教学 | `src/lib/sentence-study/service.ts`、现有教学附件 | 用完整材料作为展示范围，而不是用未评分队列代替全文 |
| 单句/整题/无提示练习，局部修正，先存输出再回复 | `src/lib/coaching/contracts.ts`、`service.ts` | 就地连接这些能力；追溯本次尝试之前看过的帮助 |
| 错误审核、记忆、正确形式出现记录 | `src/lib/coaching/learning-memory.ts` | 保留来源和提示条件，增加源练习与后续尝试关系，不把一次正确当稳定掌握 |
| 老师记忆检索 | `src/lib/app-services/memory.ts` | 目前基于词面重叠；用明确话题/意图关系改进，不能声称已有可靠跨题迁移 |
| 回答对照 | `src/lib/app-services/answer-comparison.ts` | 目前要求同题；相关问题中的表现需要另记证据，不能强塞进同题比较 |
| FreeTalk 到期内容提示 | `src/lib/app-services/chat.ts` | 仍有旧轻学习来源；迁移为当前有效句子/学习记忆适配，不复活旧模式 |

已确认的两项缺陷：

- `core-service.ts` 的 learn 过滤 `!progress.has(card.id)`，导致完整题目呈现为剩余未评分片段。
- 首页有恢复记录就绕过选择页；活动/暂停页缺少换题出口。后端支持保留旧会话并另建具体题目会话。

另外，`answer_independent` 当前隐藏本次页面提示，但其 assisted 判断不追溯另一 practice 刚看过的帮助。因此应称“本次页面无提示”，不能直接称为延迟独立掌握。不能事后补造历史提示状态。

## 四、候选用户路线

这是待确认方案，不立即取代当前默认。

1. 用户选择一道真实想回答的题。有原材料时完整显示原意与遮挡英文；没有材料时复用现有中文/英文/混合输入。允许直接开始说，也允许先看示范，不增加开始前问卷。
2. 整题同页，桌面意义片段左右对应、窄屏上下对应。题目和必要上下文清楚可见，不强迫一次翻译完整长段。
3. 卡在某个意思时，主动拖动/点击揭晓对应表达，听本句声音或打开现有讲解。默认不采用悬停经过就泄露答案，不自动调用 AI。
4. 已审核材料能回答的帮助先本地展示；不够时明确点击“问老师”，用户知道会调用文本 API。优先处理用户指定的卡点，更多问题折叠，不强制修完所有错误。
5. 帮助关闭后可以原地再说、修改自己的尝试，也可继续表达后面的意思。不必重新提交整段，不设无限重做或完成门槛。
6. 用户愿意时，回到完整回答，尝试不按参考答案逐字复现。自然等价表达可以接受；语义变化先澄清，不能用单一参考串判错。
7. 下次打开时，保留现有到期复习；额外提供可跳过的一道相关问题，把先前关注的表达放回交际目的。不是自动在后台发消息，也不是要求每次都测验。

原创示意：在解释阅读习惯时接触 `stay focused`；之后可用“学习时什么最容易让你分心？”创造相关表达机会。用户回答 `I get distracted pretty easily` 也可能完成交际任务，不因没有复述目标词组判错；此时该词组的直接提取能力仍可能是证据不足。

中文提示可随时收起或再打开；不是一开始禁用中文，也不是永久要求看中文翻译。口头练习允许用户自己说，输入框/系统听写可选；未录音时系统不能自动知道真实停顿、发音或是否已口头表达。

## 五、五个工作包与依赖

### A. 完整材料与自由进出：确定要修的基础问题

- 分离完整展示范围、未学/到期选择范围和本次可结算范围。
- 明确继续、换题、从头查看，不删除暂停记录，不把新选择解析成旧会话恢复。
- 完整题序和来源版本一致；已撤销材料不能因旧客户端缓存恢复可学。
- 旧会话队列与待提交事件保留，不在历史队列前静默插句或重写评分。
- 已学句可以查看/本地再练，不能重复初始化记忆状态或自动延长间隔。

交付：部分句已有评分的整题仍可完整查看；学习一处后换题、回来继续，原记录不变。此包独立交付，不等待新研究功能。

### B. 整题连续工作区：先可逆原型，再决定是否默认

- 复用完整材料、逐词揭晓、高亮、音频与教学，减少强制的页面/阶段切换。
- 一处整题草稿、可选局部求助；阅读位置、求助范围和输入可恢复。
- 讲解按需出现，不把全文变成长篇教材；不为布局生成第二份自然回答。
- 拖动不逐帧请求；当前句音频优先、下一句按需准备；缓存未命中时不承诺即时高质量发声。
- 原型不替换生产默认，不新建另一套学习数据库。先允许切回当前页面。

扩展条件：确实减少找位置/翻页，没有增加误揭晓与长文压力，能顺利接回自己原本想说的话。如果必须再加大量导航才能使用，就应缩减或停止扩展。

### C. 连续求助与输出证据：复用现有老师

- 将首次尝试、明确求助、看过的文本/声音提示、局部修正及后续输出关联到同一次练习。
- 优先引用现有消息/事件/材料版本；仅补缺失关系及必要快照，不重复保存整份私人原文。
- 细分来源与提示条件，至少能区别本次无提示、看中文、看过英文、看反馈后修正及时间间隔。缺证据记未知。
- 现有 Companion 反馈支持自由局部重说；不强迫英文占位、逐字复述、自动制卡或录音。
- 真实错误独立审核后才能入记忆；风格偏好、自然同义、转写不确定、高亮不当错误。
- 错误记忆和观察到的正确表现均不直接覆盖 FSRS；撤销、删除、迟到结果继续受保护。

依赖 A 的范围和版本语义，可与 B 的纯界面工作部分并行。首次数据关系变更先确定事件合同；是否需要迁移由当前 schema 决定，必要时从实际最新版本后追加并先备份。

### D. 相关问题中的再次使用：小范围验证，不建新课程平台

- 用少量明确、审核过的表达意图/话题关系，从已有题库提出一个相关问题；不是只凭英文关键词重叠。
- 关联源练习、后续题目、首次输出、发生时间及帮助使用。时间与句子 FSRS 分开，不把所有目标强行换成新的记忆曲线。
- 首次作答前不把原答案、目标表达或带答案的例句带到界面和问题文本。
- 对已有句子错误记忆的检索接入当前来源，处理 FreeTalk 仍用旧轻学习目录的适配问题。
- 判定先看是否完成交际意图，再区分目标用法正确出现、问题重复、自然替代、证据不足。不同问题不能仅按旧中文覆盖率打分。
- 可跳过或换问题；不要求每次学习后接受迁移任务，不新增任务打卡或排行榜。

依赖 C。先做少量原创/可公开测试关系与私人材料的本地关联，不全库生成场景、不新增向量数据库。LLM 动态反馈沿用现有明确付费入口。

### E. 可信交付与小规模真实比较

- 定向验证 A 的部分已学、恢复、换题及原 FSRS 保留。
- 验证 B/C 的提示曝光、草稿、已评分/未评分、只读查看、再练、换页、断网、响应丢失及跨窗口。
- 验证 D 的相关任务不提前泄露目标、自然替代不判错、没提到旧错误不判改善、撤销记忆不复活。
- 生产产物下检查已有规模的响应，区分 DOM 交互、服务端数据、冷启动和外部 API；不拿 Mock 音频证明真实声音延迟。
- 桌面、窄屏、键盘集中检查，执行相应风险测试和最终质量门。已知 Windows 原生退出只记录，不展开调查。
- 本机工程完成、真实 API 可用、用户喜欢、学习效果四项分别报告。

依赖顺序：A → B 小原型；A → C；B 体验通过且 C 完成 → D 小范围；E 随各包验证并最终收束。

## 六、评分必须先说清楚，不能为了简洁暗改

- 阅读/揭晓/听音频/高亮/草稿都不是 Good。整题“看完了”不能分摊为每句成功。
- 原型先不改变既有 FSRS、到期时间或评分事件。现有评分继续针对稳定句子 ID，保留自评与更正语义。
- 若正式采用自由流动工作区，建议评分不再成为浏览下一片段的门槛；只有明确提交的自评才调度。
- 未评分但接触过的内容不能被遗忘在系统中。候选做法是作为“待首次回想”与真正 FSRS 到期项区分，不伪造首次 Good、到期时间或成绩。该变化须随工作区正式方案一起确认，不能在原型中静默落地。
- 跨题自然表达的观察先留在现有证据链；若将来想用于自动调度，需要单独验证，不在本轮顺带实现。

## 七、怎么判断值得继续

先做可用性小试：完整进入、自由求助、继续表达、换题和恢复是否成立。然后在少量难度与初始熟悉度相近的内容上，比当前页面和新工作区：

1. 相同总时长，操作/等待占比是否下降；纯思考时间不能算无效时间。
2. 次日及约一周后，先不看答案，关键意思是否能自然表达；不同提示条件分开。
3. 相关新问题中是否有自然使用，不能只测同一篇答案熟练度。
4. 是否愿意主动打开、是否更少因流程而退出；不只看“觉得更简单”。

这是个人小规模产品决策，不是随机对照试验，也不能证明大众提分。尝试条件要记录；接触同一内容会产生练习/顺序影响。少量人工复核优先于让同一个生成模型自证，是否需要录音与真实服务由用户另行选择。文字结果不能报告发音、语调或完整 IELTS 分数。

若只有当场熟悉度提升、延迟与迁移没有改善，不继续添加图片、积分或更多步骤来解释失败；保留已证实有用的查找/反馈能力，重新检验假设。

## 八、费用、隐私和不做事项

- 开发额度不是功能目标，也不是应用 Runtime 余额。本轮真实 Runtime 授权仍为零；旧 19 次文本、4 条语音授权不能续用。
- 可以投入开发 Agent 做架构梳理、原创夹具、窄范围内容/意图关联及独立审核、恢复/性能/隐私验证；不以重复全库审查消耗额度。
- 用户日后点击在线老师反馈可能产生回复与独立审核请求，必须明确成本路径；自动化继续使用 Mock、隔离库，真实验证另定请求总上限。
- 不新增安卓/同步、公开社交社区、排行榜、多个学习模式、全库场景图、视频采集、强制录音或本地语音模型。
- 不全库重新生成教学，不更换既有自然声音配置，不因开发模型或额度变化升级依赖。
- 原文、历史、私人草稿、音频、审核证据与 API Key 不进入公开研究材料。此备忘仅包含工程路径、文献及明确标注的原创示意。
- 本文新增不构成功能版本更新或 GitHub 发布；实施和发布应在范围确认后按既有规则执行。
