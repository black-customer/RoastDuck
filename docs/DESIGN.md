## 全站共享框架

- 根布局统一使用 AppShell：桌面常驻 216px 左导航，主内容使用剩余宽度，最大 1512px；中屏左导航 192px。
- 767px 以下为单列 Web 页面，可展开导航；支持 Escape 收起并回到导航按钮，不再使用原生 App 式底部导航。
- 首页、题库、题目学习包、个人词书、公共词书与详情、语块、学习、聊天、回答编辑、搜索、设置、内容管理、加载和错误页共用框架。
- 每页只有一个 main，支持跳到主要内容。页面只负责自己的任务布局，保留原 URL 和返回行为。
- 学习内部保留约 760px 阅读宽度，外部仍为完整桌面框架；盲听时不显示答案或提供泄露答案的右栏。
- 聊天为消息区加右侧题目上下文，手机可展开题目提示。首页使用学习主区加复习、随机题辅区。

## 行为

- 首页、题库、详情和学习包共享题目状态，不把“有回答但没有材料”显示成正在分析。
- 开始回答、实际处理中、处理失败、材料待处理、学习中、可重答、前后对比均有明确入口。
- 搜索区分加载、空结果和失败，失败可重试；未成功的内容操作不从列表消失。
- 查询默认只读；学习录音只在主动点击后请求；自动化语音拒绝真实 Runtime 调用。
- 语块来源链接已修复为真实题目链接；回答页播放按钮不再覆盖题意。

## Gap 提取 V3 实验界面

- 首次学习与到期复习先展示中文意图、人物关系和具体场景，英文输入框自动获得焦点；页面只提示使用系统听写，不请求浏览器麦克风权限。
- `retrieval_prompt`、`review_prompt`、主动回忆和迁移提取阶段都隐藏目标英文，同时不渲染 Chloe 入口，防止用户在作答前通过历史消息或问答取得答案。
- 答案揭示后的比较页并排展示“你的表达”和“推荐表达”，分别可播放自然美式音频；讲解按是否已经会表达自动展开或折叠。
- Chloe 只在答案已经揭示的比较、教学和结果阶段出现。桌面为右下入口和右侧对话抽屉，768–1150px 使用 44px 紧凑入口，移动端入口与页头并列、对话为底部抽屉。
- Chloe 抽屉具有 dialog 语义和完整焦点生命周期：打开后聚焦关闭键或输入框，Tab 留在抽屉内，Escape 关闭并把焦点归还入口；关闭和发送控件均达到至少 44px 触控尺寸。
- 390px 首次提取与 1280px 比较页的真实截图为 `.impeccable/review/gap-v3-mobile.png`、`.impeccable/review/gap-v3-desktop.png`。1024px 浏览器测试使用真实矩形相交判定，确认紧凑入口不遮挡当前主操作。
- 该界面只服务 `gap_retrieval_v3` 受控实验；旧 V2 会话仍按原体验恢复，7 天体验接受前不得把 V3 写成全项目唯一正式流程。
