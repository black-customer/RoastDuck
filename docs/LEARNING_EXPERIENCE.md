# 学习体验：统一轻松学 V2
状态：现行，2026-09-08；实现证据见 PROJECT_STATUS。
现行体验版本 `light_study_v2`；`light_study_v1` 只保留记录与待确认事件对账；`four_step_v1` 仅为用户主动选择的强化。
## 一组表达
中文意思和必要中文句意 → 揭晓参考英文及短例句/声音 → 自评揭晓前是否想起 → 下一项。
新学、到期复习、首页继续和题目入口使用同一流程，无输入/录音/Judge要求。手动揭晓默认，可选5秒（默认关闭），后台暂停且到时只揭晓不翻卡。
每组最多5个不同学习项；没想起优先、模糊其次，最多重现3项，每项一次且隔至少3个其他表达。不能满足间隔的留待复习，不制造填充任务。
## 旧记录接续
V1的历史接触、评分、队列和事件保留。未完成会话在明确继续操作时建立V2继任，未学顺序保留、按5项分批；旧链接解析到继任。GET只读，不生成记录。
过渡期先对账/去重旧浏览器未确认事件；不把旧advance解释为回想正确。旧已完成会话只读历史；用户不再进入V1教学或选择版本。
## 复习与证据
首见自评是诊断，接触24小时后首复习；组内巩固不额外结算FSRS。正式复习三档映射Again/Hard/Good，不强制错题当批反复通过。
同一稳定学习项共享进度；不写四步成绩或客观掌握。暂停、刷新、重复请求和版本冲突有恢复语义。
## 材料与重答
主结果是简短反馈、学习数量、轻松学按钮；四列、全文、原文/账本按需展开，四步次级。
可暂不学、恢复、反馈、收藏与备注；这些动作不等于掌握，不自动重生成资料。
无提示重答仅题目，先封存英文再可选补中文；新Attempt关联旧回答但不覆盖。只做文本可证明的改善/重复/新问题/证据不足，不评分发音或流利度。
## 声音
声音和学习进度独立。揭晓前不出声，切卡/离页停止，迟到请求仅缓存。
统一持久偏好和真实音源标识；默认MiMo美式Chloe，失败自动备用并显示原因。短表达/例句分别可播，无需听完才能继续。
