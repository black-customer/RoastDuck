# 学习体验：整题句子学习
状态：2026-09-15当前，CONTEXT_WORKSPACE优先；GUIDED_REVEAL与SENTENCE_STUDY保留历史及技术兼容。
## 一个循环
整题中文与磨砂英文同页对应→按需跟手揭晓/可选草稿/教学→就地再练或自评。完整上下文一直保留；浏览、换句与换题没有评分门槛。无计时、无分组、无自动回插；全部拖开不自动跳页或发声。
三档评价原本的表现：脱口而出(Good)、想出来了(Hard，自己最终想对)、遇到卡壳(Again，关键意思需帮助)。自然等价表达可以成功；提示使用单独记账，不推导独立输出能力。
## 调度和更正
句子独立FSRS，目标保持率90%、日级调度、保留fuzz；首次真实自评初始化。未评分单句实际接触安排一次24小时后首次回想，不造Good。已有FSRS不被浏览或非目标自评改写。整句自评不能批量当旧语块成功。
最近评分可更正：按原评分前状态和原时刻重算，不增加次数。看上一句不改成绩。跨窗口先对账原事件，只归档真正拒绝的冲突。
本机持久事件队列先保留操作，再即时更新界面，服务端顺序确认；共享缓存视图不是唯一待提交存储。撤销/变更材料不能经恢复或重复回执重新出现。
## 可选输出
不评分也能随时本地再练。隐藏当前英文/教学/前次输入后按中文再次输出，可空、可跳过，揭晓后对照。默认不调用AI；显式请老师反馈才使用Runtime。
整题可选中文辅助→自由修正→无提示独立回答。老师接受局部更正和自然同义，始终可跳过。原文先保存，失败可恢复；反馈不自动制卡，确认错误独立审核后记忆，可撤销。
辅助与独立输出分别记录，不按同日复述判稳定掌握。无提示阶段隐藏旧中文、参考答案和历史提示，但保留此前得到帮助的事实与时间；24小时内帮助采用保守辅助标记，这是产品口径而非能力阈值。相关题不提前泄露旧目标，未观察到不等于已修复。
完整回答可保存原声/上传，亦可只留文字；只存声音不调用AI。后补文字标明并非自动转写；回听默认原速，同题同提示条件优先。个人备注不变成自动进步评分。
## 活动与来源
暂停/结束展示实际接触与真实到期安排，可换题或练完整表达。上海日期按稳定句子去重，保留旧表达历史；主动单句揭晓、教学或开始播放可计学习活动，打开/滚动/输入不计。活动和评分都不冒充客观掌握。
根据英文整理的中文明确标记。补充中文先显示旧理解和新原意，确认后生成追加版本。
中文原意强烈推荐但不强制；纯英文提交可跳过提醒。个人中英文黄色高亮仅表示关注，保存到对应文本版本，不改变评分或自动创建记忆。原错句在“看看我之前怎么说”折叠；老师仅按审核证据使用相关错误，不让用户背错句。
