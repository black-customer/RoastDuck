# 学习体验：整题句子学习
状态：2026-09-10当前，SENTENCE_STUDY优先。
## 一个循环
完整中文意思与必要语境→自行回想→看自然表达→英文与重点用法/注意点→三档自评→下一句。整题连续，无计时、无分组、无自动回插；音频和展开说明不作前置条件。
三档评价揭晓前的表现：脱口而出(Good)、想了一会儿(Hard，自己最终想对)、没想出来(Again)。自然等价表达可以成功。
## 调度和更正
句子独立FSRS，目标保持率90%、日级调度、保留fuzz；首见自评初始化。整句自评不能批量当旧语块成功。
最近评分可更正：按原评分前状态和原时刻重算，不增加次数。看上一句不改成绩。跨窗口先对账原事件，只归档真正拒绝的冲突。
本机持久事件队列先保留操作，再即时更新界面，服务端顺序确认；共享缓存视图不是唯一待提交存储。撤销/变更材料不能经恢复或重复回执重新出现。
## 可选输出
再表达一次默认关闭。开启后自评完隐藏英文，按中文再次输出，系统听写或键盘均可。
整题可选中文辅助→自由修正→无提示独立回答。老师接受局部更正和自然同义，始终可跳过。原文先保存，失败可恢复；反馈不自动制卡，确认错误独立审核后记忆，可撤销。
辅助与独立输出分别记录，不按同日复述判稳定掌握。无提示阶段隐藏旧中文、参考答案和历史提示。
## 活动与来源
结束展示本次句子及真实到期时间，可回看、选择下一题或练完整表达。累计主指标为学过的句子，旧表达数量单独保留；上海日期活动分别去重，打开/浏览/揭晓不制造掌握。
根据英文整理的中文明确标记。补充中文先显示旧理解和新原意，确认后生成追加版本。
中文原意强烈推荐但不强制；纯英文提交可跳过提醒。个人中英文黄色高亮仅表示关注，保存到对应文本版本，不改变评分或自动创建记忆。原错句在“看看我之前怎么说”折叠；老师仅按审核证据使用相关错误，不让用户背错句。
