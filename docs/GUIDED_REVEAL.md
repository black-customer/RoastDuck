# 跟手揭晓、完整教学与轻量再练

状态：2026-09-11 用户批准的 v0.3.0 增量；本文件优先于旧句子学习中的评分后自动切句。实施基准 8a348a0；未完成状态以 PROJECT_STATUS 为准。

## 路线
中文及磨砂遮挡英文、可选草稿 → 跟手按单词揭晓（不自动跳页/发声）→ 看自然表达与讲解 → 脱口而出/想出来了/遇到卡壳 → 下一句或本地再练。整题连续、无倒计时、无强制输出。再练隐藏答案/教学/前次输入，揭晓后对照；只有主动请老师反馈才调用 Runtime。

## 证据和恢复
跟手游标、最大已见范围、草稿、阶段单独保存，不推断正确/错误或独立输出。评分和进入下一句分离；Good/Hard/Again 仍是自评，只有首次评分及其明确更正影响 FSRS。更正使用原 before/原时间，再练不二次结算。旧会话先对账旧事件，再升级体验，保留旧请求语义和历史。未确认写入不冒充同步成功。

## 教学合同
sentence-teaching-v1 逐句覆盖中文意义，解释选择/结构/易混淆词，适合迁移的结构给1–2个原创双语例句，其他自然说法说明条件。简单内容简短教，不堆同义词；默认简洁分段，例句/辨析展开。教学与新材料一起生成、独立审核、覆盖检查，不能用机械模板批准内容。旧任务合同不变。
全部当前有效已发布材料离线补齐，不扩展退役历史。作者与审核上下文/runId分开，私人正文和产物仅 data/imports/private。只补教学不改句子身份/文本版本/原进度；语义错误追加修订并保持自然全文一致，实质变化不继承旧成绩；原文、旧版、旧高亮保留。

v35先备份。复用句子版本、会话、事件及独立FSRS。跟手本地即时更新，输入和游标本机持久保存后合并检查点，不逐帧HTTP。第一步及再练不发声；第二步沿用Milo/en-US、倍速与真实音源。键盘/触屏/复制/读屏不能提前泄露遮挡内容。
