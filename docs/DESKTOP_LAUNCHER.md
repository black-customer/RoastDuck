# 桌面快捷方式

> 状态：现行桌面入口规范。轻学习复用既有启动方式及构建隔离，不重新安装或改动快捷方式。

桌面的「鱼块学英语」快捷方式是本地 Web 应用入口，不是另一个原生 App。

## 用户操作

- 双击桌面图标即可启动本地服务并用默认浏览器打开；首次启动可能稍慢。
- 重复打开会复用同一项目的本地服务，不重复启动后台进程。
- 关闭浏览器不删除进度；后台服务保留至退出或电脑重启，下次双击会自动启动。
- 无需自己打开终端。启动失败显示可反馈的错误，不自动重装依赖、不结束其他程序。

## 实现与边界

- 可选本机配置 `data/desktop/runtime.json` 指定已验证的 Node 可执行文件（不提交Git）。桌面服务与完整质量门共用此选择；不修改系统PATH、依赖或快捷方式。未配置则沿用当前Node，配置失效明确报错，不能静默回到曾出现异常的版本。
- 本机Node24.13曾出现原生退出；24.19虽曾通过26项E2E，但最新完整质量门也复现相同原生退出，尚未解决。运行时选择用于可复现诊断，不是稳定性修复。配置的验证版本与实际版本不同时告警并重新验证；健康旧服务被复用时不宣称它已经更换运行时。

- 默认只监听 `127.0.0.1:3001`，不暴露到局域网。
- `/api/health` 只返回应用标识和项目目录摘要，不查询私人内容，不调用 AI。
- 快捷方式直接运行项目已有的 Node 程序，不通过 PowerShell、不设置执行策略例外；启动期间窗口最小化，无需用户操作终端。
- 启动器用端口独占锁防止并发重复启动，仅清理已退出启动器的锁；端口被其他服务占用时拒绝抢占。
- 使用开发服务器以自动呈现后续更新，不要求用户每次手动构建。桌面服务输出到 `.next-desktop`，普通开发使用 `.next`，质量门使用 `.next-e2e`；三者互相隔离。
- 服务日志和 PID 信息只存本机 `data/desktop/`，不提交 Git；快捷方式与图标均不含密钥。
- 图标是自有蓝白几何鱼形：两块独立形状表示「鱼」与「语块」，无文字、无复杂装饰；SVG 为源，ICO 包含 16–256px 七种尺寸。
- 生成图标：`node scripts/desktop/build-icon.mjs`；安装：`powershell -NoProfile -File scripts/desktop/install.ps1`。写桌面需要宿主授权。
- 项目迁移位置后重新运行安装脚本；不会覆盖同名的其他软件快捷方式。

这项完成不代表 V0.2 的内容、界面或 7 天真实使用已验收。
