# v0.4.0：整题工作区、完整回答录音与历史对比

状态：2026-09-15 用户批准实施。优先于 GUIDED_REVEAL 中强制按句推进/评分的旧默认；旧合同与历史记录保留。基线 8d4264c；实际完成情况见 PROJECT_STATUS。

## 产品路线

以已认可的演示为视觉和交互基准：选题/继续 → 自由表达 → 已审核的自然回答与教学 → 整题同页、按需揭晓与求助 → 可选重说 → 间隔复习 → 相关问题再次使用。首页两主入口，继续/换题显式选择；整题材料完整按原序显示，已评分不删除上下文。蓝色品牌、灰蓝阅读面，桌面左右对应，窄屏上下对应；不复制演示字幕、鼠标、示例成绩或预设回复。

无倒计时、分组、自动回插或强制输出。揭晓、教学、草稿与本地再练不以评分为前置。主动揭晓/教学/单句音频播放才记接触；纯打开、滚动或输入不记接触。未评分首见仅安排约24小时后的首次回想，不伪造Good；第一次真实评分初始化独立日级FSRS（90%目标保持率，Good/Hard/Again）。正式目标与全文上下文分离，非目标自评/再练不重结算；更正按原before与原时刻。评分/接触/辅助输出/独立输出分别记账。

## 协议与兼容

新增 context-workspace-v1；完整cards、targetIds、focusId、逐句练习状态分开。旧客户端语义不变，待提交事件先对账，再继任为新体验；保留旧事件/草稿/成绩。事件ID/负载/会话和材料版本校验；跨窗口不将旧内容套到新句。原材料、教学、高亮不全库重生成。暂不学退出训练提醒但保留必要上下文；撤销/误教风险材料不能继续作为正确示范。

Coaching复用Companion，关联首次输出、提示暴露、帮助和后续修正。相关问题不使用旧中文当新观点、不提前泄露目标；自然变体可接受，未观察到不当改善。FreeTalk默认语境接当前句子与已审记忆，不用旧轻学习到期表驱动新主线。确认错误独立审核后入可撤销记忆，不自动制卡或覆盖FSRS。

## 完整回答与录音

初答、中文辅助整题重答、无提示整题重答和相关新题均提供录音与上传，两者可选。仅点击录音才请求麦克风。音频只到本机服务端，不转写、不发AI、不做声学评分；音频独立保存正常，附加文字再显式分析，不能冒充逐字转写。

每次完整提交有稳定身份，引用现有草稿/答题版本/Coaching消息/相关任务，不替换原ID。保留录音/上传来源、日期、提示条件和原始文件；新回答不覆盖旧音频。草稿录音/权限申请/上传重试/局部修正不当正式回答次数。录音安全上限10分钟、单文件50MiB，支持检查后的MP3/M4A/WAV/WebM/Ogg。文件类型按内容校验，时长未知如实显示。录音先分片持久化，上传可重试；中断片段不冒充完整录音。停止/离页释放麦克风，录音开始先停示范播放。

历史可按同题任选两次回听，优先相同提示条件的最早/最近；原速1×、单路播放、可下载/备注。条件不同明示，不按时长自动判断进步。移除可恢复，永久删除单独确认；不删除其他引用，旧备份不能远程擦除。原始音频在data/imports/private/answer-audio，blob URL只作临时播放，不作持久身份。
