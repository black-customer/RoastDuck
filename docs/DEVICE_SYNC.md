# 独立安卓与本机同步契约

> 2026-09-08：实现冻结，保留数据和代码；当前网页收敛不继续本功能开发或开放入口。

状态：现行，2026-09-08。范围来自 LIGHT_STUDY_V2_ANDROID；下列实现不等于真机验收，结果见 PROJECT_STATUS。

## 数据与证据

- v26 保存设备身份、回答草稿和独立 Runtime 请求回执；v27 保存记忆清空代次/来源截止点及可恢复提取任务，区分普通草稿、编辑版本和先封存英文的独立重答。
- v28 为业务记录建立带父版本的不可变变更信封、当前投影、接收游标、冲突和任务归属。只在主动同步时扫描白名单记录，不复制/替换数据库文件，不导出 Key、Runtime 请求秘密或私人原件目录。
- 接收页必须携带 from/cursor；事务中验证 from 是已确认位置，乱序页不能越过缺页确认。重复信封按哈希去重；本地离线修改先入账，再接收远端。
- 同基础版本并发自评保留双方原记录，较弱自评/较早到期优先，不把两次同基础成功累加延长间隔。轻学习、自评、四步完成与客观掌握仍分账。
- 删除/撤销优先。记忆处理包含版本后代与来源消息截止点；清空前的在途提取不能写回，另一端从旧消息提取出的新 ID 也不能绕过清空。
- 同一聊天离线续聊发生冲突时保存明确分支。分支以冲突消息和前序消息的因果关系为界，不永久按设备路由；保留原消息 ID/正文。复盘审核允许追溯真实分支来源，但仍核查每个原文引用，不能伪造对话。
- 生成/训练会话有归属设备；导入的活跃会话只读，本机不能直接写入另一端进度。原设备暂停并同步后，才能显式接续。正在返回的聊天回复按用户消息的实际分支提交，不按失效的旧会话序号静默丢弃。

## 配对与传输

- 电脑 Web 入口绑定回环地址。设置中的显式操作才启动专用私人 IPv4 TLS 监听；不开放整个 Next 后台、不自动添加防火墙规则或公网转发。
- 配对二维码包含短期一次性凭据与 SHA-256 证书指纹；电脑和手机显示相同确认码，电脑明确同意后才发放设备凭据。设备凭据可以撤销，不属于学习数据。
- Android 只允许固定的同步路由；证书固定校验、有效期和系统主机名校验同时保留。禁止 trust-all、关闭主机名校验或改用 HTTP。
- 原生 API Key/配对秘密由不同命名空间的 Keystore 密钥保护，HTTP 层读取；不向 JS 返回这些秘密。扫码只在主动操作时请求相机，不申请学习录音权限。
- 音频按逻辑内容哈希与文件字节 SHA-256 分别识别，分块、校验、断点恢复，仅传已经缓存的文件；同步不调用 MiMo。文件检查失败不算缓存可用。

## 备份与构建

- 备份采用 PBKDF2-SHA256（310000 次）和 AES-256-GCM，认证头与压缩内容一同校验。用户自行保管密码，无法找回。恢复合并历史，不清空现有记录，不包含 API Key/配对秘密；音频可再从电脑同步。
- 安卓原生 SQLite 升级前关闭连接、备份并校验，不静默覆盖未知结构。开发/仪器测试使用 .debug 包与独立 QA 库。
- 发行包必须内置正式页面，Gradle 和构建脚本均拒绝 QA/harness/server.url。签名仅保存在忽略的 data/android-signing，并建立字节哈希一致的本机备份；不自动换签名、卸载旧包或清用户数据。
- 真实用户手机、实际 API、模拟器与 Mock 的结果分别留证。构建出 APK 不等于升级/断网/同步/学习效果全部验收。
