# 极简首页、可信材料与低阻力学习

状态：现行；2026-09-08 Product Owner 批准。与旧文档冲突时本契约优先；实施基准 8627898，完成事实见 PROJECT_STATUS。

- 首页仅学习记录、十二周蓝色热力图与学习/复习两个主入口；其他功能从菜单进入。无未完会话时按题/自动组选，已有会话按模式及具体 ID 恢复。
- 显式 learn/review 和全部来源筛选贯穿概况、创建、恢复。复习只取到期，自动组选不调用 AI，不恢复退役内容。
- 先自动核对未确认事件，再显示失败；同 ID/版本/负载重试，冲突不把旧评分套到新卡，浏览器清理失败不冒充服务端未保存。
- 热力图按上海日期、稳定学习项去重，exposure/diagnostic_exposure/self_report/consolidation 为活动；巩固不增加 FSRS 结算或累计新学。其他操作不记学习日。色级 0、1–4、5–9、10+；不补造缺失日期，不补签/惩罚。
- 轻松学 V2 与 Good/Hard/Again 独立日级 FSRS 不改；五项有限巩固，无强制输入/录音/判分。三档中性视觉；结束展示最后一次回想、最早复习及可展开对照。
- 全量复核实施快照中的当前可学材料，按需修订，开发 Agent 离线零 Runtime。只修有问题内容，原文/旧版本保留，独立 Reviewer 审核目标和每句正确示范。
- 新材料 personal-spoken-v2 增加 recallPromptZh、recallAnswerEn、可选 pattern；具体实例与中文对应，模板不充当完整答案。旧任务固定旧合同。相同目标经受审核的来源映射保留学习项 ID/进度/偏好；新目标不继承旧成绩。
- 完整自然回答保留原意与有效个人话语功能；不拿未修正的原文作教学例句。准备与真实错误分开，明确意思充分覆盖，ASR/事实不确定保持待确认。
- 同一回答里先正确、后明确说错属于使用不稳定；前次正确不能自动抵消后次修复价值。保留有证据的巩固目标，不声称用户完全不会；同意图多处错误可合并来源共享目标。
- evidence-exclusion-v1 由新建任务或已保存的材料来源绑定，Reviewer只能一致确认、不能自行开启：仅编辑整理、没有确认语言错误或未表达意图的repair单元，可凭当前单元纯英文成功引用及理由裁决不制卡；missing和使用不稳定不可跳过。全文仍须逐句审核。未标政策的旧快照保持原Prompt/Schema和校验，不放宽旧门。
- FreeTalk 去重复导航、空右栏、常驻次要设置；默认短回合一个重点，保留统一记忆、消息保存与审核。错误给中文原因，原始码在诊断详情。
- 本轮仅网页版本机交付。安卓/同步/上传/邮件设置不在范围；不调查 Windows 偶发退出，真实 API/语音/学习效果留用户后续确认。
- 按风险专项测试，最终一次完整网页检查；Mock 隔离库不动真实进度。视觉集中检查与修正，不重复全面 Review。技能作为实现方法，不扩大产品范围。
