## 产品规则
- 普通回答用一个输入框，中/英/混合均可，中文先行是建议而非限制。原文先存，稳定提交与失败续跑；无提示重答仍先封存英文。
- 明确意图没有英文表达成功证据时默认生成准备项；真实错误生成修复项。简单不省略，准确自然表达不升级制卡。事实冲突/ASR不确定待确认，不阻塞明确部分。
- 问题数与学习目标数分离。自然全文保留事实、立场、话语功能与个人口吻；语气词功能性转换，不机械添加。四阶段独立证据、版本快照与全文审核（含零项）保留。
- 新材料用personal-spoken-v1；旧合同不改写。10题历史试点离线Agent处理，网络0，追加版本、保留旧进度。
- 我的雅思表达/我的对话表达为两个固定来源视图。同意思学习项共享进度，不同义项不按英文串误合并；不恢复旧books/公共Chunk。
- 轻松学V2：中文→揭晓→脱口而出/想了一会儿/没想出来。想了一会儿仍需正确回想。五项/组，最多三项一次巩固，隔三个不同表达；不强制输入/录音/判对。
- light-fsrs-days-v1：独立FSRS，retention=.9、enable_short_term=false、fuzz=true；Good/Hard/Again。首见即初始化，自评不冒充客观成功；巩固不重复grade。旧due不批量重算，仅后续真实事件使用新策略。首次固定24h规则退役。
- 已掌握（自评）独立停推，可搜索/查看/恢复，不清历史；恢复沿用原due。新错误提示恢复，不擅自撤销手工选择。
- 快速回顾独立遮挡/揭晓/播放，GET资料只读，无学习事件/评分/FSRS；声音请求和缓存可正常产生。
- 累计学过、自评已会未学、待学/到期分开；隐藏/快速回顾不计成绩。中文准备与独立英文回答分别解释，不作客观掌握宣传。
- MiMo mimo-v2.5-tts、Dean男声/en-US；日常/雅思自然节奏，尊重明确偏好。当前/下一项实际音频预取，优先级/取消/迟到不插播；不全库合成。
