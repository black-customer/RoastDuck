# 已有回答的离线四步材料恢复

> 状态：现行来源/离线发布规范。新增轻学习共享这些审核材料，不重新生成，不回迁词书。

2026-09-07。目标是已有真实回答直接可学，不让用户逐条发起 Runtime 生成；不恢复词书。

## 资料与证据

- 只读盘点全部未被替代的历史回答、当前口语 Attempt 和真实对话。被替代的原片段保留原文、修订关联与计数，不重复当作待处理答案。
- 导出到 `data/imports/private/four-step-recovery/`，保存原文、题目、稳定 ID、来源哈希和逐句索引；索引只是定位工具，不是语义诊断。
- Agent 对每句作出自然／修复／缺失／不确定／非答案判断。中文只按原文整理；题目翻译、指令不能冒充回答意图。缺少中文时只诊断英文能证明的问题。
- 独立内容 Reviewer 在新的上下文读取原文和候选，不读生成推理；逐项裁决必要性与材料正确性。审核后自动可学，不要求用户手工批准。
- 离线证据与 Runtime `ai_runs` 分开存储，记录 Agent 身份、独立上下文、Prompt、输入输出哈希和 runId；网络调用为 0。
- 发布复用当前 `evidence_v2` 编译器和四步引擎。来源原文不能被改写，学习进度不能由导入生成。导入幂等，应用前备份。

## 旧回答适配

为每份有效 `personal_answers` 建立稳定、可追溯的口语 Attempt 映射。保留原回答表及所有版本，不把 AI 修订文当用户原回答。映射后的记录在题库只计一次，旧链接跳转到对应新训练资料。原始创建时间与回答顺序保留。

混合回答通过 v23 的追加式切分修订处理：保留父记录原文与全部旧版本，保存连续字符分类、独立审核、题目映射和子回答 ID。父记录退出当前答案计数，旧链接仍可回看并进入各个子回答。不把同题重答合并，不把换题后的回答绑定首题。纯题目列表／指令也保留分类证据，但不冒充一次有效作答或“无需强化”。

## 真实可用性闸门

CI 的 Mock 测试不代表本机内容就绪。另行报告：有效来源总数、可学、审核确认无需训练、不确定待确认、失败、未处理、被替代历史。全部来源必须有结果；未处理不能用已回答或已完成学习掩盖。复核每道已回答题目的主入口能到达相应材料。

题目详情必须优先读当前 Attempt 的已审核 `practice_materials`：展示该次回答的待练项和证据，不再用旧 `question_learning_units` 数量判断有无教材。旧账本仅作历史兼容视图；同一题的原始回答、派生尝试与首屏主动作共享来源排序，不将晚写入的离线材料误当成晚作答。

## 服务失败

失败页应显示安全的具体失败阶段和原因，保留原回答。超时、格式错误、引用不匹配、审核拒绝分开处理，不能全部显示为服务失败，也不能放宽审核来制造可用假象。
