# Speaking Studio：按题重答与 AI 老师契约

> 状态：兼容，保留旧题库/口语行为参考，不规定轻学习步骤；当前范围见PRODUCT。

> 2026-09-06：以下为历史实现／兼容说明，不再约束新建学习。当前按回答／对话四步强化，权威为 PRODUCT.md、LEARNING_EXPERIENCE.md、FOUR_STEP_RECOVERY.md；不恢复词书或逐项双语境发布依赖。

Speaking Studio 是 V0.2 的输出闭环。它不是一次性评分表单，也不是实时全双工语音聊天，而是可恢复的、微信式异步师生对话。

## 进入条件

- 用户可以从题库显式开始首次回答；仅打开题目详情不得创建 attempt。
- 题目存在必学项时，所有必学项至少完成一次完整学习轮后，主动作变为“重新回答这道题”。
- 用户仍可查看历史回答、问题账本和学习进度，不被强制进入对话。

## 输入自由度

每条用户消息允许：

- 纯英文；
- 纯中文；
- 中英混合；
- 先英文回答，再用中文解释想表达的意思；
- 语音输入后编辑本地 ASR 转写文本。

DeepSeek 只接收用户确认后的文本，不接收原始录音。

## 会话形态

- 默认四轮师生往返，之后用户可继续或结束。
- UI 使用连续消息流：文字气泡、语音气泡、发送状态、重试状态和历史时间分组。
- 老师一次可以连续发送 1–4 条短消息，模拟自然教学节奏。
- 所有消息先持久化为可重试状态；AI 失败不能吞掉用户消息，幂等重试不能重复入库。

## AI 老师每轮职责

按需组合以下动作，不要求每轮机械全部执行：

1. 自然回应用户表达的内容；
2. 只聚焦一个当前最重要的问题；
3. 给出保留用户原意的地道表达和一个短例句；
4. 要求用户当场重说；
5. 根据回答继续追问。

老师优先自然复用本题刚学表达，并最多带入两个其他到期表达；不符合当前语境时不得强塞。判断目标是“是否自然传达同一意思”，不是逐字复述标准答案。

## Runtime AI 阶段

运行时流水线拆分为独立请求：

1. teacher_response：生成自然教学回复；
2. gap_generator：从当前回答提出候选 Gap；
3. gap_reviewer：用独立 Prompt、上下文、请求和 runId 审核候选；
4. reattempt_comparator：比较旧 Gap、已学表达和新 Gap；
5. learning_material_compiler：仅为审核通过且适合学习的 Gap 生成学习材料。

所有角色只从 DEEPSEEK_MODEL=deepseek-v4-flash 读取模型名，返回必须通过版本化 Zod Schema。失败时展示可恢复状态，不用规则结果伪装 AI 成功。

## 重答比较

每次显式完成回答后生成：

- improved：旧 Gap 未再出现，或目标表达能独立自然使用；
- repeated：旧 Gap 再次出现；
- new：出现新的高置信问题；
- uncertain：缺乏证据或可能由 ASR 导致。

同一表达只有在不同日期的独立回答中正确使用至少两次，并完成到期复习后，才自动标记为已掌握。

## Gap 写入规则

- 普通英文点击查询绝不写 Gap。
- AI Generator 不能直接写入词书；必须经独立 Reviewer。
- 所有确认问题进入 Gap 账本。
- 只有高价值、可复用并适合当前学习闭环的搭配、句型、功能表达和语法构式进入唯一个人词书“我的雅思答案”。
- 篇章与内容组织问题进入老师追问或结构练习，不伪装成 Chunk。
- asr_uncertain 默认进入待确认区，不生成学习卡。
- 用户可以隐藏、修改、撤销或报告自动学习项。

## 主要接口

- POST /api/questions/:id/reattempts
- POST /api/speaking/sessions
- GET /api/speaking/sessions/:id
- POST /api/speaking/sessions/:id/messages
- POST /api/speech/transcriptions
- POST /api/speech/synthesis

## 非目标

- 实时全双工语音聊天；
- 自动发音、重音、语速评分；
- 强制背诵 Band 9 范文；
- 向 DeepSeek 上传录音；
- 登录、云同步和多人协作。
