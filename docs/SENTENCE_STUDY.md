## 唯一默认路线
选题 → 中文/英文/混合想法 → 原文保存、原意诊断、独立审核的自然回答 → 中文句子回想 → 看自然表达、用法与注意点 → 脱口而出/想了一会儿/没想出来 → 下一句 → 句子FSRS → 可选老师输出。
整题按自然顺序连续学习，随时暂停；无倒计时、无五项分组、无自动薄弱句回插、无强制输入或判对。句子自评不代表旧语块掌握。首页仅真实活动记录与学习/复习，按题或选择一个有材料的题目；复习仅到期句子。旧模式只在 /extensions 主动进入，不占默认恢复/到期队列。

## 材料和版本
sentence-material-v1：保留事实、立场和个人口吻；每个明确完整意思有句子和中文提示。用户中文与根据英文整理的中文分开标记；混合文本中的中文也是来源。自然正确句也可学习，但不虚构错误。用法采用准确文本范围，注意点有本次来源证据；长句按完整意思划分，同句多目标不重复。原文/材料/审核版本保留；开发期现有材料全部离线复用、定向修复并独立审核，不消费Runtime。

## 评分与恢复
句子独立FSRS：90%目标保持率、日级、Good/Hard/Again；首见自评初始化。旧分数不回填句子。最近评分可修改，从原评分前状态按原时刻重新结算；不重复增加学习记录。后台顺序提交、本地持久待提交队列；冲突不把旧答案套到新句，不在未确认时假报已同步。热力图区分句子与旧表达历史。

## 可选输出
再表达一次默认关闭；句子辅助、整题中文辅助、无提示整题通过同一老师线程给反馈，允许局部修正、跳过。无提示阶段仅题目；反馈不自动制卡，确认问题经独立审核入可撤销学习记忆。自然同义可接受，没有音频不做发音/流利度评分。Runtime DeepSeek V4.1 Flash（deepseek-flash）；普通揭晓/评分不调用文本AI。

## 性能、界面和声音
日常桌面入口运行预构建生产版本；缓存绑定已审核材料指纹和规则版本，点击只查有效状态/版本。预备学习包、本地揭晓和可靠暂存使切句即时。蓝色品牌+贯穿视口的灰蓝底，正文/用法/辅助清楚分层，固定动作位置。按代码实现推进，不强制图像三方案；集中看真实长短内容与窄屏。
MiMo Milo/en-US：跟练句和全文优先自然声音、允许等待及显式快捷试听；其他快捷播放优先已有音频，否则立即本机声音。声线/口音/播放倍速独立，当前/下一句按需准备，不全库合成，揭晓前不播放，迟到响应不插播。
